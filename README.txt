Harizma AI — локальный проект лендинга

Актуальная версия: index.html (та же страница есть в figma-rebuild.html).
Откройте этот файл в браузере. Для локального сервера можно запустить в этой папке:
  python -m http.server 8000
Затем открыть http://localhost:8000/

В проекте сохранены предыдущие варианты страниц, веб-видео, шрифты и изображения.
